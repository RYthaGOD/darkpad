## 2. Key Generation & Setup

### 2.1 Protocol Treasury
This key controls the protocol parameters.
**Generate**:
```bash
solana-keygen new -o protocol-treasury.json
```
**Location**: Project Root (`/`)

### 2.2 Program Deploy Keys
These keys control the smart contract code (upgradability).
**Generate** (done automatically by `anchor build`, but strictly managed):
```bash
# Launchpad
solana-keygen new -o target/deploy/launchpad-keypair.json

# Verifier
solana-keygen new -o target/deploy/verifier-keypair.json
```

### 2.3 ZK Verification Key (`vk.bin`)
Generated by Noir/Barretenberg.
```bash
# In circuits/check_eligibility/
nargo compile
bb write_vk -b ./target/check_eligibility.json -o ./vk.bin
# Copy to program
cp ./vk.bin ../../programs/verifier/vk.bin
```

## 4. Operational Security (OpSec)

1.  **Rotation**: If `protocol-treasury.json` is ever exposed, run `solana-keygen new` immediately and update the program authority using the old key (if possible) or migrate.
2.  **Cold Storage**: For Mainnet, use a **Hardware Wallet** (Ledger/Trezor) for the Upgrade Authority and Treasury. Do not keep hot keys in `target/deploy`.
3.  **Multisig**: Transfer authority to a Squads V4 Multisig immediately after deployment.
